# Supabase Edge Functions

Deploy using Supabase CLI. Configure `CRON_SECRET`, `WHATSAPP_PHONE_NUMBER_ID`, `WHATSAPP_ACCESS_TOKEN`, `WHATSAPP_API_VERSION`, `WHATSAPP_TEMPLATE_NAME`, and `WHATSAPP_TEMPLATE_LANGUAGE` as Supabase Edge Function Secrets. Supabase supplies URL and server key. Never commit actual keys.
